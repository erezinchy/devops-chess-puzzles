Chess Puzzle Trainer has been deployed!

To check the status:
  kubectl get pods -n {{ .Values.namespace }}

To access the application:
{{- if .Values.ingress.enabled }}
  The app is available through the Ingress controller.
  kubectl get ingress -n {{ .Values.namespace }}
{{- else }}
  kubectl port-forward svc/frontend 8080:80 -n {{ .Values.namespace }}
  Then open http://localhost:8080
{{- end }}

To view logs:
  kubectl logs -l app=backend -n {{ .Values.namespace }}
  kubectl logs -l app=frontend -n {{ .Values.namespace }}
